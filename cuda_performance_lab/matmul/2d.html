5. 全链路数据流可视化

有效数据 越界补0 选中/负责 本线程加载（同列跨行） aReg（按列取） bReg（按行取） tmp

A Tile（As，共享内存）

橙色虚线框=本线程加载的 4 个元素：同一列 inner_col_A，行号 inner_row_A + k·STRIDE_A（k=0..3）。A 是跨行（列固定）。

B Tile（Bs，共享内存）

橙色虚线框=本线程加载的 4 个元素：同一列 inner_col_B，行号 inner_row_B + k·STRIDE_B（k=0..3）。B 也是跨行（列固定），只是 B tile 行数少、列数多。

aReg[TM]

TM 个，按列取

aReg[i] = As[(thread_row·TM+i)·BK + dotIdx]：固定 dotIdx 列，取 thread_row·TM+i 行。

bReg[TN]

TN 个，按行取

bReg[j] = Bs[dotIdx·BN + thread_col·TN+j]：固定 dotIdx 行，取 thread_col·TN+j 列。

tmp[TM][TN]

TM×TN

tmp[i][j] += aReg[i]·bReg[j]，外积累加。当前展示 dotIdx 轮。

C Tile（输出，全局内存）

BM×BN

绿色=本线程负责的 TM×TN 输出块。

写回映射：tmp → C

TM×TN

每个 tmp[i][j] 写到 C 的 (gRow+i, gCol+j)，越界则跳过。
