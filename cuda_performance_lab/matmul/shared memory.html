1. 配置实验

默认 M=N=K=64、BLOCKSIZE=8：grid 为 8×8，共 64 个 Block；每个 Block 有 8×8=64 个线程。为了让边界情况更直观，可以把 M/N/K 改成非 8 倍数，例如 50、45、37。BLOCKSIZE 控制在 8 以下可让线程网格和 Tile 可视化更清晰。

Grid 中的 Block

点击 Block 选择它。每个小格代表一个 Block，横向坐标是 blockIdx.x，纵向坐标是 blockIdx.y。

当前 Block 的 Thread（BS×BS）

点击任意 Thread，右侧会显示 threadIdx.x、threadRow、threadCol、全局坐标和内存访问。Thread 索引按一维排列：threadIdx.x = threadRow×BLOCKSIZE + threadCol。
